# Changelog

All notable changes to VFE MHTML 001 are recorded here.

## [001 build1] - 2026-07-27

### Added

- First release of VFE MHTML 001.
- Active-tab MHTML capture through Chrome's native page capture API.
- Save As dialog with sanitized page-title and UTC timestamp filenames.
- VFE-branded popup interface and icon set.
- MIT license, privacy policy, security policy, and installation documentation.

### Security

- No host permissions.
- No API keys, tokens, private keys, `.env` files, hard-coded credentials, remote scripts, analytics, advertisements, or third-party libraries.
